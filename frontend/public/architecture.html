Design Highlights
Fully on-premises — no data leaves the court network
9-node LangGraph pipeline with 4-way parallel search phase
Dual LLM — Qwen 2.5 (EN) + JAIS 7B (AR) bilingual support
RBAC — Admin inherits Judge & Clerk permissions via hierarchy
BGE-M3 semantic search + BGE Reranker over DIFC precedents
Precision@5 · Recall@5 · MRR evaluation metrics built-in
JWT auto-refresh — Axios interceptor retries on 401
6-service Docker Compose with health checks & restart policies
